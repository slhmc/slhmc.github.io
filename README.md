# Smile LauncHer website

Одностраничный сайт Minecraft-лаунчера SLH: Vite + TypeScript, RU/EN, заставка с логотипом и интерактивное превью. Без серверной части, аналитики и внешних шрифтов.

## Запуск и проверка

Node.js 24 LTS и npm:

```powershell
npm ci
npm run dev
```

Адрес: http://127.0.0.1:3001. Порт фиксирован; сервер на 3000 не затрагивается.

```powershell
npm test
npm run build
# После остановки dev-сервера:
npm run preview
```

Готовый сайт находится в `dist/`.

## Изображения и превью

- `public/assets/preview/RU` и `EN`: исходные 34 изображения 2560 × 1355. Некоторые `.png` содержат JPEG.
- `npm run images`: создаёт оптимизированные изображения и `src/image-manifest.ts`. После замены оригиналов выполнить эту команду и тесты.
- Полноразмерный WebP используется только там, где он меньше оригинала, с точным сохранением пикселей. Мобильные копии — 1024 × 542, WebP near-lossless.
- При входе загружается только Home выбранного языка. Предзагрузка начинается вблизи превью: на компьютере последовательно, с низким приоритетом; на телефоне — следующий слайд. При экономии трафика/2G предзагрузка отключается.
- Полноэкранный режим загружает полноразмерный экран и останавливает прокрутку страницы. Крестик и Escape закрывают превью; для окна создания сборки Escape сначала закрывает это окно.
- Выбранная сборка 26.2 сохраняется при переходах и смене языка. При ошибке загрузки сохраняется прежнее изображение и предлагается повторить.
- На телефонах доступны перемешанные слайды, пауза, стрелки и свайпы. Полноценное интерактивное превью открывается на весь экран; в портретной ориентации предусмотрен поворот интерфейса.
- `prefers-reduced-motion` отключает анимации и плавную прокрутку; автоматические слайды первоначально на паузе.

Основные файлы: `src/i18n.ts` — тексты; `src/screens.ts` — переходы и области нажатия; `src/demo.ts` — превью; `src/scroll.ts` — прокрутка; `src/style.css` — оформление. Язык сохраняется в localStorage, прохождение заставки — в sessionStorage.

## GitHub Pages

Репозиторий: https://github.com/slhmc/slhmc.github.io

Адрес: https://slhmc.github.io/

В Settings → Pages выбрать **GitHub Actions**. Workflow `.github/workflows/deploy.yml` при обновлении `main` устанавливает зависимости, запускает тесты, собирает сайт и публикует только `dist`. Можно запустить вручную через Actions. Локальная команда `npm run build` сама ничего не публикует.

В репозитории хранятся исходники, ассеты и lockfile. `node_modules` и `dist` исключены из Git. Для корневого адреса `slhmc.github.io` подходит стандартный Vite base `/`.

По согласованию репозиторий остаётся публичным: GitHub Pages из приватного репозитория организации требует платного тарифа.

## Проверки

Тесты проверяют достижимость всех экранов RU/EN, размеры и координаты, сохранение выбора сборки, возврат из создания, перемешивание слайдов, ошибки/повторную загрузку, мобильные размеры и точное сохранение пикселей полноразмерных изображений.

Ручная проверка: первый вход и раскрытие заставки; 360/768/1440 px; прокрутка при открытом полном превью; RU/EN; клавиатура и Escape; переключение размеров окна и ошибки загрузки.

Данные сравнения ≈10 МБ, ≈70 МБ и ≈30% предоставлены автором, что отмечено на странице. Лаунчер: https://github.com/slhmc/slh. Discord: https://discord.gg/yhTvuB6U8n.
