# Smile LauncHer website

Одностраничный сайт Minecraft-лаунчера SLH: Vite + TypeScript, RU/EN, заставка с логотипом и интерактивное превью. Без серверной части, аналитики и внешних шрифтов.

Лаунчер: https://github.com/slhmc/slh. Discord: https://discord.gg/96TSZg9ZeA.

## Скачивание

Сайт получает последний опубликованный версионный релиз `slhmc/slh` через GitHub API, включая предварительные релизы. Черновики, технический тег `launcher-updates` и файлы автообновления исключены. Версия и статус релиза видны над загрузками.

Windows, macOS и Linux доступны всегда. Определённая ОС компьютера показана первой; телефоны, iPad, ChromeOS и неизвестные платформы получают общий выбор. Для macOS явно доступны Intel и Apple Silicon, поскольку браузер не всегда достоверно сообщает архитектуру процессора. Кнопки скачивают реальные файлы выбранного релиза: EXE/MSI/Portable ZIP, DMG/App ZIP и DEB/RPM/AppImage. Установщик пользователь запускает самостоятельно.

При ошибке API или ограничении запросов сайт использует `src/release-snapshot.json`, показывает предупреждение и кнопку повторной проверки. Снимок обновляется при сборке, в том числе ежедневной публикацией Pages. Токен GitHub в браузере не используется.

## Проверка и публикация

Node.js 24: `npm ci`, `npm test`, `npm run build`. Для разработки: `npm run dev` (http://127.0.0.1:3001).

Обновление `main` запускает `.github/workflows/deploy.yml`: тесты, сборку и публикацию `dist` на https://slhmc.github.io/. Параметр Pages в репозитории: GitHub Actions.
